A1 Agent 指挥舱优先（推荐）

首页就是主控台：用户直接描述目标，Agent 给计划、调工具、展示过程。最符合“真实 Agent 平台”。

适合

  • 突出平台差异化
  • 让 Agent 价值一眼可见
  • 统一承载课程、图谱、任务、诊断

风险

  • 信息层级必须克制
  • 需要处理好新手引导

A2 学习路径优先

首页先帮用户进入课程和训练路径，Agent 作为助手随时解释、推荐和纠偏。更亲和，学习用户更容易上手。

适合

  • 学生和教师
  • 降低首次使用压力
  • 已有课程模块可复用较多

风险

  • Agent 可能显得不够核心
  • 平台差异化弱一些

A3 图谱指挥中心

首页围绕知识图谱展开，Agent 解释用户当前位置、能力缺口和下一步补强路径。记忆点最强。

适合

  • 强调专业度
  • 突出 166 节点图谱资产
  • 适合能力诊断和补强场景

风险

  • 新用户理解成本较高
  • 视觉实现复杂度更高

A4 运营控制台

优先完成登录、模型配置、诊断、历史会话、管理状态。最快落地，但更像后台系统。

适合

  • 内部测试和运维配置
  • 快速交付可用系统
  • 管理功能清楚

风险

  • 用户端吸引力不足
  • 不够像 Agent 产品
我的建议

建议选 A1，并吸收 A2 的新手引导。

理由：A1 能让“真实 Agent 平台”的价值最直接；A2 的学习路径可以放进首次使用、空状态和推荐下一步里，避免新用户迷路。
