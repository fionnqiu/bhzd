# 音频语音分段与时间对齐的边界对齐规则

本资料解释 BHZD 平台音频分段任务的边界判定、强制对齐与时长一致性。读者对象是语音标注员、ASR 数据质检员。

## 语音分段：核心定义

语音分段指将一段录音按可听语音活动（speech activity）切分为多个区间，并为每个区间附加转写文本与起止时间戳。对齐（alignment）指转写文本与音频区间在毫秒级时间轴上的对应关系。

区间采用左闭右开约定：`[start_ms, end_ms)`，最小颗粒度为毫秒整数。

## 语音分段：分段边界判定

边界应满足以下条件之一：

- 静音超过 200 ms 的位置可作为分段边界。
- 说话人切换处的位置必须作为边界。
- 显著语气停顿（含语气词"嗯""呃"）超过 350 ms 的位置可作为边界。

不满足条件的连续语音不应被切分。强行切分会丢失单词边界信息。

## 语音分段：时间对齐要点

对齐时遵循以下要点：

- 实际可听事件起止与时间戳偏差 ≤ 50 ms 即视为合格；超过 100 ms 需复核。
- 同一文本被多段语音覆盖时，应按段落或句子而不是单字拆段。
- 数字、缩写、特殊符号的边界按其可读起止计，不按字符宽度。
- 区间不能超过音频总长度；超过会判为时间错配。
- 区间应保持顺序且不重叠；出现重叠应合并或拆段，禁止自动排序。

## 语音分段：边界误差容忍度

按训练 / 测试场景区分容忍度：

- 训练集：边界偏差 ≤ 30 ms。
- 测试集：边界偏差 ≤ 50 ms。
- 质检抽检：边界偏差 ≤ 100 ms。

超出的样本需要标注员重新听音并调整。无法确认的样本应打回"待核验"。

## 语音分段：与外部格式的边界

外部事实与本项目边界：

- Kaldi segments、Praat TextGrid 都支持毫秒级整数区间（外部事实）。
- 本项目采用 `[start_ms, end_ms)` 毫秒整数属于本地约定；其他系统的帧号或采样点索引不能直接迁移。
- 标注员不应把 0.025 s 等小数时间塞入整数字段；如确实需要小数，应升级到项目约定，而不是擅自处理。

## 语音分段：常见误区

- 把语气停顿当作静音错切，造成短句被断开。
- 用帧号代替毫秒，导入不同采样率项目时崩溃。
- 同一说话人内的喘息声不计入区间，导致后续 ASR 训练数据丢失。
- 把整段背景音乐当作语音区间。

## 语音分段：示例与反例

正例（虚构示例）：6 秒音频中，普通话句子"今天，天气不错"在 0.5 至 3.2 秒，感叹句"对吧"在 3.8 至 4.7 秒。提交两段区间并附对应转写文本。

反例：把两个句子合并为 0.5 至 4.7 秒，丢失句间停顿与边界，模型学不到语气特征。
