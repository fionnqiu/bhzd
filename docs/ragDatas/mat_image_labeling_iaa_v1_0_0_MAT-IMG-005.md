# 图像多标注员一致性 Cohen κ 与重叠率评估方法

本资料解释 BHZD 平台图像标注多标注员一致性（IAA）的 Cohen κ 计算、重叠率评估以及质检抽样设计。读者对象是质检工程师和教学管理员。

## 多标注员一致性：核心定义

Cohen κ 是衡量两名标注员在 N 个样本上对 K 个互斥类别标注一致性的指标。相比简单一致率，它对"随机一致"做了修正。

κ = (p_o - p_e) / (1 - p_e)，其中 `p_o` 是观察到的一致率，`p_e` 是期望一致率（按类别边缘分布推算）。

## 多标注员一致性：判读区间

κ 的判读区间（参考 Landis & Koch 1977）：

| κ 范围 | 一致性水平 | 适用建议 |
| --- | --- | --- |
| < 0 | 差于随机 | 检查样本与词表 |
| 0 至 0.20 | 微弱 | 重新培训或修订词表 |
| 0.21 至 0.40 | 一般 | 复核标注指南 |
| 0.41 至 0.60 | 中等 | 加强抽检 |
| 0.61 至 0.80 | 良好 | 可发布，配合抽检 |
| 0.81 至 1.00 | 极佳 | 可低抽检频率 |

BHZD 平台发布门槛为图像分类任务 κ ≥ 0.7、关键点任务一致性通过即可，实例分割通过 mask IoU 单独评估。

## 多标注员一致性：重叠率评估

图像目标检测/分割任务除 κ 外还使用重叠率：

- 矩形框：IoU（交并比）≥ 0.5 视为命中，≥ 0.75 视为高质量。
- 实例分割 mask：mIoU ≥ 0.6 视为良好。
- 关键点：PCK@0.2 ≥ 0.85 视为通过。

重叠率应使用相同图像、相同 `category` 的两名标注员的结果。

## 多标注员一致性：抽样与轮换

抽样设计：

- 每次发布前抽取不少于 200 张图像的双标注结果。
- 高风险图像（密集小目标、严重遮挡）单独加抽。
- 标注员轮换：每 4 小时轮换标注员避免疲劳，跨组别双标注。
- 数据回流：将 κ 较低的样本加入"边界样本库"作为培训材料。

仅依靠小样本 κ 易受波动影响，应同时汇报置信区间。

## 多标注员一致性：常见误区

- 用简单一致率代替 Cohen κ，未校正随机一致。
- 在样本数 < 100 时汇报 κ，结果不稳定。
- 把多标注员一致性扩展到 3 人以上而不切换 Fleiss κ。
- 不汇报边缘分布，导致读数误导。

## 多标注员一致性：示例与反例

正例（虚构示例）：200 张行人图像双标注，Cohen κ=0.78，标注员 A、B 一致率 87%，期望一致率 42%，因此 κ 良好。

反例：直接汇报"准确率 87%"而忽略期望一致率，无法判断随机基准上的提升是否真实。
