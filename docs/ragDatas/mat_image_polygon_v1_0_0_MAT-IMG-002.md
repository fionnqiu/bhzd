# 图像多边形顶点标注的闭合顺序与最小顶点数规则

本资料覆盖 BHZD 平台多边形标注的顶点数与顺序约定、最小形状规范、复杂目标处理。读者对象是图像标注员、视觉质检员和教学管理员。

## 多边形标注：核心定义

多边形标注由有序顶点序列 `[(x1,y1), (x2,y2), ..., (xn,yn)]` 构成。第一个顶点和最后一个顶点必须相连以闭合图形。

本项目采用"顺时针顺序、闭合首位相同"的存储约定。导入其他格式时必须先重排顶点。

## 多边形标注：最小顶点数与简化

- 最小顶点数为 3。任何少于 3 个顶点的"多边形"应改用矩形框或点标注。
- 长条形或弧形目标应在曲率显著变化处放置顶点，避免无意义的密集顶点。
- 单条直线无需多边形，应改用线段标注。
- 高密度图像（如遥感）允许使用简化版本，但顶点间距不低于 4 像素。

## 多边形标注：复杂目标

- 镂空目标（如甜甜圈、空心 O）：使用"外多边形 + 内多边形"双层结构，分别记录 `outer_points` 与 `inner_points`。
- 多部件目标（椅子 + 桌腿）使用 `group_id` 关联，不通过多边形合成。
- 多边形遮挡时按完整目标轮廓标注，并设置 `occluded=true`，不要按可见部分裁剪。
- 毛发/丝状目标按可识别主轮廓标注，过细部位允许简化。

## 多边形标注：边界误差与质量

- 顶点偏移容忍度：边界像素 ≤ 2 像素。
- 顶点间距：相邻顶点间距应 ≥ 4 像素，避免重复密集点。
- 顶点顺序一致性：质检脚本按顺时针重排后比较关键点 IoU。

过细的多边形会带来解析性能问题，应在发布前做简化处理。

## 多边形标注：常见误区

- 在密集顶点上堆砌却顺序混乱，导致可视化与训练脱节。
- 镂空目标只用单层多边形，导致后续 mask 化失败。
- 多部件目标硬性合并为一个大轮廓，导致训练时模型无法分割。
- 在曲率极低位置加顶点造成顶点冗余。

## 多边形标注：示例与反例

正例（虚构示例）：汽车轮廓多边形从左前轮至车顶到右后轮顺序闭合 14 个顶点，全部为整数像素。

反例：从车顶出发逆时针到右后轮再到左前轮闭合 6 个顶点，部分顶点缺少关键转角，模型无法学到完整车形。
