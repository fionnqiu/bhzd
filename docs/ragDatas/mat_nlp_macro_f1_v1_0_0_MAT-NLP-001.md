# 文本分类任务中宏平均 F1 的定义、计算步骤与适用条件

本资料围绕文本分类任务的"宏平均 F1（Macro-F1）"指标，回答它的定义、计算步骤、适用场景、不适用场景以及常见误用。读者对象是 BHZD 标航智导平台上的标注质检工程师与教学管理员，面向验证集或学员练习结果的得分解释。

## 宏平均 F1：核心定义

宏平均 F1 先对每一个类别单独计算 F1（精确率与召回率的调和均值），再对所有类别的 F1 取算术平均，因此每个类别在最终得分中具有相同权重。它忽略每个类别的样本数量差异，适用于希望同等关注少数类和多数类的多分类任务。

## 宏平均 F1：计算步骤

计算输入为一个二分类或多分类任务的预测结果集合，每条样本同时具有真实标签 `y_true` 与预测标签 `y_pred`。

1. 列出全部类别集合 `C = {c1, c2, ..., cn}`，n 为类别总数。
2. 对每个类别 `ci`，按"该类为正类、其他类为负类"的二分类口径计算精确率 `precision_i` 与召回率 `recall_i`。
3. 对每个类别计算 F1：`F1_i = 2 × precision_i × recall_i / (precision_i + recall_i)`。当 `precision_i + recall_i = 0` 时，F1 约定为 0。
4. 取所有类别的算术平均：`MacroF1 = (1/n) × Σ F1_i`。

计算示例（虚构三分类结果）：假设 30 条样本，类别为 `A / B / C`。

| 类别 | 精确率 | 召回率 | F1 |
| --- | --- | --- | --- |
| A | 0.80 | 0.67 | 0.73 |
| B | 0.60 | 0.86 | 0.71 |
| C | 0.50 | 0.40 | 0.44 |

宏平均 F1 = (0.73 + 0.71 + 0.44) / 3 ≈ 0.63。该结果说明 C 类拉低了整体表现，需要单独检查 C 类样本。

## 宏平均 F1：适用条件

宏平均 F1 适合以下场景：

- 类别数量固定且样本分布不均，但仍希望每个类别都得到同等评估权重的多分类任务。
- 少数类的误分类同样会造成业务损失，例如投诉分类中的"重大投诉"类别。
- 需要对比两种模型在所有类别上的整体平衡表现，而不是被高频类别主导。

## 宏平均 F1：不适用条件与替代指标

以下场景应改用或同时使用其他指标：

- 关心整体样本分类正确率：使用准确率 `accuracy`，但要注意类别不平衡时的误导。
- 关注样本量大的类别表现：使用微平均 F1（Micro-F1），它等价于整体的精确率与召回率调和值。
- 类别重要性不同：使用加权 F1（Weighted F1）或单独汇报每个类别的 F1。
- 存在极端类别不平衡而少数类样本极少：宏平均 F1 可能被噪声主导，可考虑取各类别 F1 的中位数或分位数。

宏平均 F1 不能单独用于决定模型发布，必须同时给出混淆矩阵与每类指标。BHZD 平台的练习题结果解释应至少包含宏平均 F1 与微平均 F1 两项。

## 宏平均 F1：常见误区

- 将宏平均 F1 等同于"模型综合得分"：它没有考虑每类样本量，类别多的模型未必更好。
- 在 `precision + recall = 0` 时填 1：违反 F1 的定义，会高估极差类别的贡献。
- 在不平衡数据上单独看宏平均 F1 改进：少数类提升几个样本可能使分数大幅波动，应结合样本量观察。
- 对二分类任务重复计算宏平均 F1：二分类只有一个宏平均 F1，常见做法是直接报告正类 F1。

## 宏平均 F1：示例与反例

正例（虚构示例）：在医疗意图分类中，类别 `emergency / appointment / general` 共 100 条样本，宏平均 F1 由 0.55 提升到 0.62，说明三类整体改善，可以继续优化。

反例：在版本对比中只汇报宏平均 F1 从 0.81 提升到 0.83，而没有列出每类指标。当 `general` 类占比 95% 时，0.83 的提升几乎全部来自 `emergency` 类的几个样本，结论不可直接采纳。
