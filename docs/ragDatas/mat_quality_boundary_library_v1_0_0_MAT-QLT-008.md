# 边界样本库的建立、维护与教学化利用

本资料覆盖 BHZD 平台"边界样本库"的建设、维护与教学转化。读者对象是质检员、教学管理员。

## 边界样本库：核心定义

边界样本库（boundary sample library）是因标注规则不清晰、词表覆盖不足、或多人判定分歧而被单独归档的样本集合。它承担"诊断—培训—标注规则迭代"三个角色。

边界样本库不替代主线数据，只作为问题诊断与教学化训练的辅助资源。

## 边界样本库：触发条件

出现以下任一情形应纳入边界样本库：

- 同一文本/图像/音频 ≥ 2 名标注员给出不同主标签，且均为合法答案。
- 同一文本/图像/音频的标注在仲裁环节出现 2 分以上分歧（主观任务）。
- 词表覆盖度检查覆盖率 < 95%。
- 标注员对相同类别连续 5 个样本出现判定摆动。
- 学生在相同题项上累计反馈集中于同一题。

任何触发都必须新建一行边界记录，不允许改写已有标注。

## 边界样本库：维护要求

- 每条记录包含样本 ID、原始内容、判定分歧列表、最终采用答案、采用理由、责任审核员。
- 状态字段：`pending / reviewed / archived / deprecated`。
- 数量阈值：边界库占总样本比例 < 8%；超出时提示词表修订。
- 保留期：通常 24 个月；过期由审核员决定归档或删除。
- SHA-256 必须保留；删除时同时清理 SHA-256。

## 边界样本库：教学化利用

边界样本可在以下场景使用：

- 学员培训题（带详细解释）。
- 校准会议研讨材料。
- 新标注员上岗测试题。
- 词表扩展的提案依据。
- AI 模型的硬例训练集（带脱敏）。

每次使用必须保留用途与引用记录，确保边界样本可追溯。

## 边界样本库：常见误区

- 把边界样本直接删除，丢失问题诊断价值。
- 把边界样本泄漏到生产数据，污染训练。
- 边界样本未脱敏，引入个人信息风险。
- 教学使用时未带"边界"上下文，误导学员。

## 边界样本库：示例与反例

正例（虚构示例）：某"非机动车"标注任务中，电动车、自行车、滑板车共同出现于一段视频；3 名标注员给出不同主标签。该样本纳入边界样本库 `boundary_id=BND-2026-001`，附仲裁结论与视频 hash。

反例：直接把高争议样本从数据集中删除，事后无法对比模型改进。
