# 跨数据类型标注员一致性评估与决策准则

本资料覆盖 BHZD 平台跨数据类型（文本/音频/图像/视频）的标注员一致性（IAA）评估方法、判读准则与决策流程。读者对象是质检工程师与教学管理员。

## 标注员一致性：核心定义

标注员一致性（Inter-Annotator Agreement, IAA）衡量多名标注员对同一样本标签的一致程度。它既反映标注质量，也反映任务词表的清晰度。

常见 IAA 指标包括 Cohen κ（2 人）、Fleiss κ（≥ 3 人）、Krippendorff α（任意数量与距离函数）。

## 标注员一致性：指标选择

按标注场景选用：

- 2 人互斥标签：Cohen κ。
- 多人互斥标签：Fleiss κ。
- 多人非互斥标签：Krippendorff α。
- 顺序 / 区间标签：Krippendorff α 的有序距离版本。
- 自由文本：Cohen κ 不适用，应使用 BLEU 或人工评审。

指标选择与样本量都必须在评估报告中声明。

## 标注员一致性：判读区间

参照 Landis & Koch 1977：

| κ/α | 一致性 | 行动 |
| --- | --- | --- |
| < 0.40 | 不可接受 | 修订词表或召回标注员 |
| 0.40 至 0.60 | 较弱 | 完善指南与培训 |
| 0.60 至 0.75 | 中等 | 增加抽检 |
| 0.75 至 0.90 | 良好 | 可以发布 |
| ≥ 0.90 | 极佳 | 低频率抽检 |

不同业务容忍区间不同；高风险领域（医学、法律）建议阈值上浮 0.05 至 0.10。

## 标注员一致性：决策流程

一致性低于阈值的处理流程：

1. 复核词表定义是否清晰，必要时补充示例。
2. 复核标注员是否经过培训，必要时重新培训。
3. 抽样检查误判样本，统计误判模式。
4. 若是边界样本本身定义不清，把样本移入"边界库"而非主线数据。
5. 修订词表或样本筛选规则后再次评估。

决策必须记录决策人、决策日期与变更版本。

## 标注员一致性：常见误区

- 仅看"准确率"忽略随机一致，可能高估一致性。
- 样本量过小（< 100）就下结论，置信区间宽。
- 用相同 κ 处理互斥与非互斥标签。
- 跨数据类型简单横向比较，不区分任务难度。

## 标注员一致性：示例与反例

正例（虚构示例）：500 条文本分类样本由 3 名标注员标注，Fleiss κ=0.78，可发布。

反例：直接汇报"3 名标注员一致率 90%"，未对随机一致做修正，遇到不平衡标签时会显著高估一致性。
