# 标航智导产品设计说明

**状态：** 已确认

**目标：** 建设一个面向数据标注实训课程的教学智能体，帮助学生理解规范、完成练习、获得反馈并形成个性化进阶路径。

## 产品定位

标航智导不是数据标注生产工具，也不是按行业场景拆分的问答助手。它以能力图谱组织教学内容，以知识讲解、正反例、练习任务、自检和诊断反馈帮助学生从不会到会完成数据标注任务。

能力图谱、任务转化、场景切换、诊断与路径推荐均为教学手段。图谱必须驱动学习顺序、关联资源和补强建议，不能退化为普通 RAG 问答的装饰性展示。

## 教学范围

教学体系覆盖四类数据标注文件类型：文本、图像、语音和视频。每个能力点必须包含学习目标、前置能力、规范依据、正反例、练习素材、答案或判定规则、常见错误和补强资源。

- 文本标注与图像标注：优先保证规则准确、来源可溯、示例清楚、练习结果可判定。
- 语音标注：作为重点实现方向，完成转写、说话人、情感、副语言、切割与对齐等深度教学闭环。
- 视频标注：在文本、图像和语音的统一教学模型基础上扩展，覆盖帧标注、目标追踪和行为事件。

四类数据类型是课程内容域，不应被任何单一行业场景替代。

## 可扩展场景

医疗、智能客服、车载语音助手和内容安全审核是首批教学案例，不是产品边界。场景层作为可扩展规则覆盖层，向能力点、知识规范、案例和练习附加业务条件；新增金融、教育或其他场景时，不得改变四类数据类型的课程主结构。

场景切换的教学价值是让学生比较同一标注能力在不同业务语境下的规则差异，而不是建立多套彼此独立的产品功能。

## 教学闭环

```text
了解当前能力 -> 学习知识与规范 -> 查看正反例 -> 完成任务练习
-> 自检或系统反馈 -> 定位薄弱能力 -> 补强资源 -> 下一学习任务
```

学生可以从一种数据类型进入，查看当前能力图谱和推荐节点，完成学习与练习，并由系统给出规则依据明确的反馈。行业场景可在讲解、任务和反馈时切换，以展示规则覆盖后的差异。

## 图谱模型

图谱以能力节点为中心，关联知识、任务、场景、资源与证书节点。前驱、包含、支撑、关联、场景挂载和证书映射等关系用于回答以下教学问题：

- 学生在学习某项能力之前还需要掌握什么。
- 该能力应使用哪些规范、案例、工具和练习。
- 当前行业场景下有哪些补充或覆盖规则。
- 学生出现错误后应回到哪个能力点补强，并学习什么内容。

## 交付边界

完整参赛作品需要交付可运行的 Web 交互式应用、图谱数据、可溯源知识库、场景规则、诊断与路径推荐、用户试用证据以及赛事要求的文档、视频和源码材料。

首期开发不以某个行业场景为主线，而是建立四类数据标注教学内容与统一图谱模型。功能的先后顺序应服从教学闭环和内容准确性，具体开发计划、验收标准和赛事提交清单将在本说明审阅后单独制定。
