# 标航智导功能验收与赛事提交清单

## 1. 功能验收

| 能力 | 必须证明的结果 | 验收证据 |
|---|---|---|
| 教学入口 | 学生能从文本、图像、语音、视频任一内容域进入学习 | 页面录屏与导航截图 |
| 图谱导航 | 能查看能力的前置、知识、任务、资源和场景关联 | 图谱操作录屏、JSON/GraphML 样本 |
| 知识讲解 | 每个已发布单元均显示目标、规则、来源、正反例和常见错误 | 内容审阅表与页面截图 |
| 练习与反馈 | 学生能完成任务并得到引用明确规则的反馈 | 每类至少一个完整练习录屏 |
| 文本与图像基线 | 规则正确、例题可判定、结果可复现 | 标准答案、判定记录、内容复核签名 |
| 语音深度教学 | 覆盖转写与标点、说话人、语种/方言、情感与副语言、唤醒词/命令词、切割与对齐六项教学链；每项至少两类练习 | 语音专项演示、素材与规则记录、诊断与补强链 |
| 视频扩展 | 覆盖帧标注、目标追踪和行为事件；仅复用图像标注原语，不复用图像能力节点 | 视频练习与图谱关联记录 |
| 场景规则覆盖 | 场景声明支持的数据类型，并为每种声明类型提供规则覆盖与案例；同一能力切换场景后有可解释变化 | 至少两场景对比录屏；场景配置文件 |
| 诊断与路径 | 错误映射到能力节点，并给出补强资源和下一任务 | 诊断报告、路径结果、回归用例 |
| 可运行性 | Windows 10/11 的最新版 Chrome 或 Edge 能访问 Web 应用；平台嵌入如使用也能运行 | 启动说明、浏览器与平台冒烟测试记录 |

## 2. 内容与数据发布门槛

- 每个已发布教学单元有可核验来源、审阅状态和练习判定方式。
- 图谱通过唯一 ID、引用完整性、前置无环和场景规则完整性校验。
- 素材具有自制、开源或授权证据；敏感数据已脱敏或未被使用。
- 不以大模型输出作为唯一规范依据；模型解释必须能回链到已发布规则。
- 结构化导出文件才可触发自动诊断和掌握度更新；截图仅提供辅助讲解。

## 3. 试用与回归

邀请 2-3 名人工智能专业师生完成同一组代表任务，记录：测试人角色、任务、完成状态、耗时、错误点、主观反馈、修订决定和复测结果。每次发布至少回归文本、图像、语音、视频各一个任务，以及一个场景切换、一个任务转化和一个诊断路径任务。

## 4. 赛事提交清单

| 目录 | 必交或建议内容 | 赛事约束 |
|---|---|---|
| `<作品编号>-01作品与答辩材料` | 可运行包、运行/依赖说明、PPT 与 PDF、答辩视频 | 答辩视频 MP4，≤10 分钟，建议不高于全高清，≤500MB |
| `<作品编号>-02素材与源码` | 源码、脚本、配置、图谱、知识库、代表性授权素材 | 总体 ≤1GB，建议 ≤500MB；超过 10 个文件时压缩 |
| `<作品编号>-03设计与开发文档` | 信息概要表 PDF、AI 使用说明与佐证、设计文档、创作说明、操作手册 | AI 辅助使用时，说明与证据必须真实且完整 |
| `<作品编号>-04作品演示视频` | 实际运行演示、3-5 幅原尺寸 JPEG 截图 | 视频 ≤5 分钟、≥1280P、MP4/MOV/AVI、≤300MB |

所有四个目录均须包含 `readme.txt`，说明目录用途和文件内容。每个文件只能出现在一个提交目录中；提交前在干净环境启动作品，并逐项核对文件大小、格式、内容和版权状态。答辩视频的“建议不高于全高清”和演示视频的“分辨率≥1280P”是不同文件的独立约束，不得互相套用。

赛事官方作品大类、小类和平台勾选项以当期大赛管理系统为最终依据。当前文档中的“交互媒体（交互式应用）”仅为拟报方向，填表前须核对官方分类；运行展示平台应勾选 Windows，并在“其他”中如实填写“Web（浏览器访问）”或按系统实际选项填写。

AI 使用说明的每条记录至少附一种真实佐证，优先使用含时间戳的关键截图；只有截图无法说明关键过程时才添加必要录屏。采纳比例统一为“该使用环节的最终交付物中，经人工修改后仍保留的 AI 输出占比”：文本按字数、代码按有效行数、图表按可见元素或决策项估算，并在备注说明计算方式。

## 5. 演示叙事验收

五分钟演示必须完整呈现一次教学闭环：输入真实或模拟岗位任务 -> 任务转化器生成按前置能力排序的任务卡 -> 选择数据类型 -> 图谱定位 -> 学习规范与正反例 -> 完成练习 -> 接收规则反馈 -> 查看补强路径 -> 对比一个行业场景规则差异。演示重点是“教学如何发生”，而不是罗列行业场景或展示普通聊天问答。
