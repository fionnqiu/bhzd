**状态说明：** 现有课程、图谱、任务转化和诊断应用已有自动化与浏览器验证；用户认证、管理员界面、真实 LLM、模型供应商管理和 Agent 指挥舱是待实施目标。清单中的目标能力只有在留下实际证据后才能标记通过。

| 文字与操作层级 | 默认界面只突出任务、状态、结果和一个主要操作；依据和参数按需展开 | 视觉评审、可用性试用记录 |

## 3. 安全与隐私验收

- 用户密码和管理员密码均使用 Argon2id；不存在默认管理员密码。
- 管理员密码哈希和模型加密主密钥来自部署环境，不写入 SQLite。
- 模型 API Key 使用 AES-256-GCM 加密；数据库、API、日志和截图中不得出现完整密钥。
- 用户与管理员使用不同 Cookie、会话表和认证中间件。
- Cookie、CSRF、登录限流、失败锁定和账号枚举防护通过测试。
- 邮箱验证和密码重置令牌只保存哈希、具有有效期并且一次性使用。
- 模型 Base URL 和可选请求头经过校验，不允许访问本机、内网元数据或覆盖危险转发头。
- 上传原文件不写入 SQLite、日志、临时目录或会话历史；异常和取消后内存引用被释放。
- 用户删除会话后，消息、Agent 运行和关联工具摘要按数据关系一并删除。

## 4. 内容与数据发布门槛

- 每个已发布教学单元有可核验来源、审阅状态和练习判定方式。
- 图谱通过唯一 ID、引用完整性、前置无环和场景规则完整性校验。
- 素材具有自制、开源或授权证据；敏感数据已脱敏或未被使用。
- 不以大模型输出作为唯一规范依据；模型解释必须回链到已发布规则或确定性工具输出。
- 结构化导出文件才可触发确定性诊断；截图和自由文本不产生自动分数。
- 真实模型协议、模型名称和平台能力以实际连接证据为准，不以配置表存在代替验证。

## 5. Windows 首期验证与试用

### 5.1 自动与真实服务验证

- Windows PowerShell 能完成依赖安装、SQLite 迁移、管理员密码哈希、启动、测试和构建。
- 运行现有 pytest、Vitest 和 Playwright 回归，以及新增服务端单元/集成测试。
- 在 Windows 最新版 Chrome 和 Edge 验证注册、登录、Agent 对话、工具内嵌、确认门、历史删除和 `/admin`。
- 四类模型适配器均通过离线契约测试；具备合法凭据的协议分别完成一次流式响应和工具调用冒烟。
- 真实验证记录必须脱敏，不能包含 API Key、管理员密码、SMTP 密码或完整认证头。

### 5.2 师生试用

邀请 2-3 名人工智能专业师生完成同一组代表任务，记录参与者角色、任务、完成状态、耗时、错误点、主观反馈、修订决定和复测结果。至少覆盖：

1. 直接描述企业任务，由 Agent 选择图谱与任务工具。
2. 完成一个课程练习并确认掌握度更新。
3. 上传一个结构化标注文件，查看诊断后决定是否保存摘要。
4. 查找一段历史会话并删除。

真实试用仍须满足内容和发布放行条件，不得由开发代理代填参与者记录。

## 6. 后续 Linux 与生产部署门槛

Linux/Docker 不属于 Windows 首期完成标准。进入后续部署前必须单独评审并验证：

- HTTPS 反向代理、安全 Cookie、可信代理和客户端 IP 获取。
- SQLite 数据卷、备份、恢复和单实例锁定。
- SMTP、模型接口的生产网络与证书。
- 日志脱敏、监控、磁盘容量和告警。
- 讯飞星辰平台托管或嵌入模式的真实账号与接口能力。

## 8. 演示叙事验收

五分钟演示应围绕一次真实 Agent 教学闭环展开：

```text
邮箱登录
-> 直接描述真实或模拟岗位任务
-> Agent 展示简明计划并自动调用图谱/课程工具
-> 在对话中查看局部图谱与任务卡预览
-> 用户确认后创建学习任务
-> 完成确定性练习并查看规则反馈
-> 上传结构化文件获得诊断预览
-> 用户确认保存摘要和掌握度变化
-> 查看按 PRE 排序的下一步补强计划
```

演示重点是 Agent 如何选择并编排可验证工具，以及用户如何保持控制权；不得只展示普通聊天，也不得把未接入的供应商或平台描述为已完成。
