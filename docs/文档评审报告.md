## A. 内部数据与规格矛盾（P0/P1）

### A1. 图谱节点数量三处口径不一致 【P0】
- `标航智导.md` 3.2 节：能力 40+ / 知识 60+ / 任务 20+ / 场景 5 / 资源 30+ / 证书 12，合计约 167。
- `标航智导.md` 4.3 节末：节点约 170、边约 240。
- `标航智导.md` 7.3 节：只列了"62+ 知识库条目、40+ 能力点、20+ 任务、5 场景"，漏掉资源节点和证书节点。
- 同时"知识节点 60+"与"知识库条目 62+"两个数并存，但文档未说明二者关系（1:1？1:N？`rule_refs` 里 `SRC-GB-45674` 和 `KNG-AUD-PUNCT-001` 究竟谁是知识库条目、谁是知识节点）。
- 影响：图谱脚本实现时无法确定到底要建多少节点、KNG 与知识库 markdown 如何映射。

### A2. 掌握度阈值与分级标准缺失 【P0】
- 7.3 节：低于 0.6 为"薄弱"。
- 5.6 节示例：目标节点掌握度 ≥0.8 才算"合格"。
- 5.3 节示例：0.8 直接显示为"已掌握"。
- 0.6–0.8 之间是什么状态（巩固中？待加强？）未定义；0.8–1.0 是否就是"已掌握"也未明说。
- 缺少统一的掌握度分级表，会导致图谱节点着色、路径推荐、"已掌握"判定各行其是。

### A3. 冷启动测评设计不合理 【P1】
- 8 章重难点：初始掌握度由入学测评（10 题）测定。
- 但能力节点 40+，10 题平均每个能力节点不到 0.25 题覆盖，无法测定 40+ 节点的初始掌握度。
- 需要明确：测评是按能力节点出题（每节点≥3 题）还是按数据类型/能力域出题（粗粒度定位）？题库从哪里来？

### A4. 可视化库选型两处打架 【P1】
- 7.3 节：前端可视化使用 D3.js / vis-network 力导向布局渲染（"或"写法）。
- 8 章重难点：使用 vis-network 力导向布局 + 按需懒加载子图（只写 vis-network）。
- 到底用哪个？还是 vis-network 为主、D3 做局部？需要二选一，避免开发期返工。

### A5. 答辩视频与演示视频的分辨率要求方向相反 【P1】
- 答辩视频（赛事模板3）：建议不高于全高清（1080P），≤500MB。
- 演示视频（赛事模板3）：≥1280P（720P 起步），≤300MB。
- "不高于全高清"与"不低于 1280P"是两个相反方向的约束，文档里没有显式区分两者，填表时容易抄错。
- 附录C 写"全高清"但没注明这是 1080P 上限还是下限。

### A6. 文件夹命名是否带作品编号前缀不一致 【P2】
- 赛事模板1 示例：`2026012345-01作品与答辩材料`（带编号）。
- `标航智导.md` 0 章：`作品编号-参赛总文件夹 / 01作品与答辩材料`（顶层带编号，子目录不带）。
- `标航智导.md` 附录C：`01作品与答辩材料/`（全部不带编号）。
- 需统一：子目录是否带作品编号前缀。

## B. 技术实现边界不明确（P1）

### B1. 掌握度更新公式完全缺失 【P1】
- 7.3 节只说"通过专项练习正确率更新；诊断模块识别错误后按错误严重度扣减"。
- 未定义：
  - 首次练习正确率 100%，掌握度从 0 跳到 1 还是按比例？
  - 多次练习如何加权（最近一次？滑动平均？衰减权重？）？
  - 错误严重度如何量化扣减（1 星扣 0.05？2 星扣 0.15？3 星扣 0.3？）？
  - 掌握度是否会自然衰减（长期不练降级）？

### B2. 最短路径算法描述逻辑混乱 【P1】
- 7.3 节："在能力子图上运行带权拓扑排序——节点难度作为权重，前驱关系作为有向边约束，使用改进的 Dijkstra"。
- 8 章重难点："带权拓扑排序+改进 Dijkstra"。
- 问题：拓扑排序求的是遍历顺序，Dijkstra 求的是最短路径，两者并用没有说明各自承担什么角色。
- 边界缺失：
  - 当前节点 A 到目标节点 Z 有多条 PRE 链，"最短"按什么度量（节点数最少？难度权重和最小？掌握度缺口最大？）？
  - 若 Z 的前驱中有节点掌握度 <0.6，是否必须先走该前驱？还是直接跳过？
  - 路径中包含已掌握节点时是否跳过其练习？

### B3. 场景切换的"规则覆盖"语义未在示例中体现 【P1】
- 数据规范 4 节：覆盖规则必须说明"替代哪条通用规则"或"新增何种业务约束"。
- 但 `标航智导.md` 5.5 节医疗场景示例只写了"标注原则 + 附加标记 + 特殊规则"，没有显式标注"替代通用规则第X条"或"新增约束Y"。
- 当通用规则与场景规则冲突时，优先级未在文档中明确（虽然直觉是场景优先）。

### B4. 任务转化器的输入边界未定义 【P1】
- 5.4 节输入"企业标注任务简短描述"，输出"学习任务卡"。
- 未定义边界：
  - 任务描述无法在图谱定位任何能力节点时，返回什么？是拒识、降级为普通问答，还是要求用户重新描述？
  - 任务跨多个能力节点（如"标注客服语音的转写+情感+说话人"）时，生成单卡还是多卡？多卡如何排序？
  - 任务描述含场景关键词（如"车载"）但学生当前场景是"通用"时，是否自动切换场景？

### B5. 诊断模块的截图自动诊断能力存疑 【P1】
- 5.6 节输入"截图/导出文件"。
- 8 章重难点："自定义插件支持 JSON/TextGrid/COCO/XML 等格式解析与可视化"。
- 但截图（PNG/JPG）如何自动诊断？需要 OCR + 结构化解析 + 规则匹配，这条链路的准确率如何保证？
- 若学生上传截图但截图不清晰、字段缺失、格式非标准，降级路径是什么？文档未提。

### B6. RAG 知识库 markdown 与图谱 KNG 节点的映射缺失 【P1】
- 7.4 节知识库是按目录组织的 markdown 文件（62+ 条）。
- 3.2 节 KNG 节点 60+。
- 两者是 1:1？还是 1:N（一个 KNG 节点挂多个规范条目）？`rule_refs` 里 `SRC-*` 和 `KNG-*` 两类 ID 的关系是什么？未说明。
- 这直接影响 RAG 检索时是按文件召回还是按节点召回。

### B7. 掌握度的"节点级"与"场景级"边界未定义 【P1】
- 5.6 节示例：客服场景下副语言标注错误，"副语言信息标注节点掌握度降至 0.4"。
- 但副语言标注在通用、客服、车载场景下规则不同。学生在客服场景错了：
  - 是降"副语言标注（通用）"的掌握度吗？
  - 还是降"副语言标注-客服场景"的掌握度？
  - 如果是前者，是否会影响他在车载场景下原本"已掌握"的状态？
- 跨场景掌握度是共享一份还是按场景独立维护，文档没有定义。

## C. 教学范围与内容边界模糊（P1）

### C1. "语音实现最深入教学闭环"无量化标准 【P1】
- 产品设计说明、开发流程、数据规范三处都强调"语音最深入"，但什么算"最深入"未量化：
  - 节点数最多（语音能力节点 vs 文本/图像/视频）？
  - 练习题最多？
  - 教学闭环完整度（学-练-诊-补四环全通）？
- M4 退出条件"学生可沿完整能力链学习、练习、纠错和补强"对所有类型都适用，没有体现"最深入"的差异化标准。

### C2. 视频与图像、视频与语音的能力边界重叠未处理 【P1】
- 数据规范 2 节视频要求"帧标注、目标追踪、行为事件"。
- 但帧标注≈图像标注（逐帧），行为事件≈音频事件（若含音轨），是否会出现重复教学？
- 视频如何"复用统一教学模型"——是复用图像的练习判定逻辑？还是复用图像的图谱节点？接口未定义。

### C3. 行业场景对数据类型的覆盖范围未定义 【P1】
- 医疗场景涉及图像（影像）、文本（病历）、语音（医嘱）多类数据。
- 车载场景主要是语音。
- 内容安全涉及音频、视频、文本。
- 边界问题：
  - 一个场景是否必须覆盖所有相关数据类型才算"场景规则覆盖"达标？
  - 医疗场景若只做了语音和影像、没做视频，算不算合规？
  - 场景节点 `SCN` 是否要求与数据类型绑定（`data_types` 字段）？数据规范 3 节只说节点含 `data_types` 字段，但未约束 SCN 必须填哪些。

### C4. "通用"是否算场景节点未明确 【P2】
- 3.2 节：场景节点首批 5，示例含"通用"。
- 5.5 节场景菜单：[场景A-D] + [默认] 通用标注规则。
- "通用"是一个 SCN 节点（与其他 4 个平级），还是"无场景"的默认状态（基础层）？
- 若是前者，通用与其他场景切换是平级关系；若是后者，通用是其他场景的父层。这影响 INSCN 边的方向设计。

### C5. 语音能力清单两份文档不一致 【P1】
- `标航智导.md` 4.3 节语音能力：转写、说话人分离、语种/方言、副语言、唤醒词/命令词、音频切割与对齐（6 项）。
- 验收清单"语音深度教学"：转写、说话人、情感、副语言、切割与对齐（5 项，缺唤醒词，多了情感）。
- 开发流程 M4：转写、说话人、情感、副语言、切割与对齐（5 项，缺唤醒词）。
- 三处清单不一致，验收时以哪个为准？
