# 标航智导 PRD 00：产品总览

> 文档版本：v3.1  
> 更新日期：2026-08-06  
> 产品名称：标航智导 - 图谱与 RAG 双驱动的数据标注能力教学智能体  
> 文档定位：产品方向、角色、总体架构、MVP 范围与验收口径

---

## 1. 产品定位

标航智导是一款面向高职人工智能技术应用专业、AI 数据标注工程师岗位的教学实训智能体平台。

产品通过“岗位能力图谱 + RAG 知识召回 + 确定性诊断工具”帮助学生完成数据标注能力学习、岗位任务训练、错误诊断和个性化补强，同时帮助教师发布岗位任务、分析学情。

---

## 2. 赛事对齐

| 比赛要求方向 | 标航智导对应能力 |
|--------------|------------------|
| 挖掘岗位能力生成岗位能力图谱 | 数据标注能力图谱、能力路径、证书映射 |
| 岗位典型工作任务转化成学习型任务 | 企业任务转学习任务卡、教师发布任务 |
| 个性化自适应学习 | 入学测评、掌握度模型、诊断补强、个性化推荐 |
| 内容专业性与可追溯 | RAG 知识库、来源台账、引用依据 |
| 智能体闭环 | Agent 指挥舱、工具调用、确认门、执行轨迹 |

---

## 3. 核心产品原则

| 原则 | 说明 |
|------|------|
| 弱导航，强目标 | 学生可以直接说目标，不必先理解功能模块 |
| Agent 不等于唯一入口 | 同时提供预设学习、图谱、任务、诊断、知识问答入口 |
| RAG 可治理 | RAG 管理仅系统管理员可进入，资料需要上传、解析、切片、审核、发布、评测和版本管理 |
| 确定性优先 | 评分、诊断、掌握度和路径由确定性工具计算 |
| 写操作需确认 | 创建任务、保存诊断、更新掌握度、发布资料等必须确认 |
| 专业回答有依据 | 涉及规范、规则、教材的回答必须展示引用来源 |

---

## 4. 用户角色

| 角色 | 核心诉求 | 主要页面 |
|------|----------|----------|
| 学生 | 学习、练习、诊断、补强、考证 | Agent 指挥舱、预设学习、能力图谱、学习任务、诊断、知识问答 |
| 教师 | 发布任务、查看学情 | 教师工作台、班级管理、教学任务发布、学情分析；不进入学生端或 RAG 管理端 |
| 内容管理员 / 教研管理员 | 使用学生端学习能力，并按教学协作权限参与教师端 | 学生端；不进入 RAG 管理端或系统管理端 |
| 系统管理员 | 配置模型、安全、权限、RAG 资料全流程，并保留学生端支持访问 | 学生端、RAG 资料库、资料上传、切片编辑、来源台账、召回测试、模型供应商、RAG 参数、用户权限、审计日志 |

## 6. 产品能力地图

| 能力域 | 子能力 |
|--------|--------|
| Agent 智能体 | 意图识别、计划生成、工具调用、执行轨迹、确认门、结果整合 |
| 预设学习 | 数据类型路径、场景路径、岗位路径、考证路径、薄弱补强路径 |
| 能力图谱 | 节点查询、PRE 路径、局部子图、掌握度 overlay、证书映射 |
| 学习任务 | 任务卡生成、任务创建、任务完成、练习反馈、任务归档 |
| 标注诊断 | 文件解析、规则诊断、错误归因、依据召回、补强计划 |
| RAG 知识库 | 系统管理员上传、解析、切片、索引、审核、发布、召回、评测 |
| 教师教学 | 班级管理、任务发布、学情分析；任务仅可选择已发布合规资料 |
| 系统管理 | 模型配置、嵌入模型、重排模型、安全配置、RAG 治理、审计 |

## 7. MVP 范围

### 7.1 必须完成

| 模块 | 功能 |
|------|------|
| 学生端 | Agent 指挥舱、预设学习、能力图谱、学习任务、标注诊断、知识问答 |
| RAG | 系统管理员上传 PDF/MD/DOCX、解析、切片、审核、发布、召回、引用 |
| 图谱 | 节点查询、PRE 路径、掌握度展示 |
| 任务 | 任务卡预览、确认创建、任务详情 |
| 诊断 | JSON/TextGrid/COCO/VOC 诊断、补强路径 |
| 管理 | 系统管理员的模型配置、RAG 参数、资料审核、来源台账 |

### 7.2 可以延后

| 模块 | 功能 |
|------|------|
| 教师端 | 完整班级管理、复杂学情报表 |
| RAG | OCR 图片解析、音视频转写、网页抓取 |
| 评测 | 大规模自动评测、AB 实验 |
| 部署 | Linux/Docker/HTTPS/监控 |

## 8. 首期关键验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC1 | 学生目标输入 | 能从自然语言目标生成学习计划 |
| AC2 | 预设学习 | 学生可从预设入口创建任务 |
| AC3 | RAG 上传 | 资料可上传、解析、切片、索引 |
| AC4 | RAG 审核 | 未审核资料不进入学生端召回 |
| AC5 | RAG 引用 | 专业回答展示来源引用 |
| AC6 | RAG 拒答 | 无可靠资料时不编造答案 |
| AC7 | 图谱推理 | 可生成 PRE 补强路径 |
| AC8 | 任务转化 | 企业任务可转学习任务卡 |
| AC9 | 标注诊断 | 上传结构化标注文件后生成诊断和补强计划 |
| AC10 | 掌握度 | 练习和诊断能更新掌握度 |
| AC11 | 确认门 | 所有写操作需要用户确认 |
| AC12 | 安全 | 密钥加密、密码哈希、上传文件不持久化 |
