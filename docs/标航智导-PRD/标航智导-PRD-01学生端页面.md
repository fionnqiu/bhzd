---

## 1. 学生端设计原则

学生端需要同时满足两类用户：

- 明确知道目标的学生：直接在 Agent 指挥舱输入目标。
- 不知道从哪学起的学生：通过预设学习、教师任务、能力薄弱推荐进入。

因此学生端首页不能只有一个空对话框，必须同时提供“目标输入”和“预设学习入口”。

学生端门户及其 API 仅允许 `student`、`content_admin` 和 `system_admin` 使用；教师账号必须跳转至教师端，直接访问学生端路由或 API 返回 403。管理员保留学生端，用于支持、演示和权限内的学习流程验证。

## 3. Agent 指挥舱

### 3.1 页面定位

学生默认首页。用于承接自然语言目标、预设学习入口、文件上传诊断、RAG 问答和任务生成。

### 3.2 页面布局

```text
Agent 指挥舱
├── 顶部栏
│   ├── 产品名称
│   ├── 当前场景选择器
│   ├── 当前模型状态
│   └── 用户入口
├── 左侧任务栏
│   ├── 今日推荐
│   ├── 正在学习
│   ├── 教师发布任务
│   └── 最近会话
├── 中部对话区
│   ├── 欢迎态
│   ├── 目标输入
│   ├── 预设学习快捷卡
│   ├── 对话流
│   ├── Agent 计划
│   └── 嵌入式工具结果
├── 右侧状态栏
│   ├── 执行轨迹
│   ├── 引用来源
│   ├── 确认门
│   └── 当前能力定位
└── 底部输入区
    ├── 文本输入
    ├── 文件上传
    ├── 快捷指令
    └── 发送按钮
```

### 3.3 欢迎态入口

| 入口 | 点击后行为 |
|------|------------|
| 文本标注入门 | 进入文本标注预设路径 |
| 图像标注入门 | 进入图像标注预设路径 |
| 语音标注入门 | 进入语音标注预设路径 |
| 视频标注入门 | 进入视频标注预设路径 |
| 岗位任务训练 | 打开岗位任务描述模板 |
| 上传结果诊断 | 打开文件上传面板 |
| 考证路径 | 展示 1+X 数据标注考证路径 |
| 今日薄弱补强 | 根据掌握度推荐一个任务 |

### 3.4 核心交互

#### 3.4.1 直接说目标

```text
学生输入目标
  ↓
Agent 识别数据类型、场景和能力
  ↓
信息不足时只追问一个关键问题
  ↓
展示简明计划
  ↓
调用 RAG、图谱、课程检索工具
  ↓
生成学习建议或任务卡预览
  ↓
学生确认后创建任务
```

#### 3.4.2 点击预设学习

```text
点击预设学习卡
  ↓
展示预设路径
  ↓
Agent 说明学习目标、预计时长、关联能力
  ↓
学生确认开始
  ↓
创建第一个学习任务
```

#### 3.4.3 上传诊断文件

```text
上传 JSON / TextGrid / COCO JSON / VOC XML
  ↓
格式校验
  ↓
确定性诊断
  ↓
RAG 召回规则依据
  ↓
图谱定位薄弱能力
  ↓
生成补强计划
  ↓
学生确认保存摘要与掌握度更新
```

### 3.5 页面状态

| 状态 | 页面表现 |
|------|----------|
| 空白态 | 显示目标输入、预设学习卡和示例问题 |
| 计划中 | 展示 Agent 计划卡 |
| 工具调用中 | 执行轨迹显示工具名、状态、耗时 |
| 等待确认 | 右侧确认门高亮，主区域展示预览 |
| 已完成 | 展示结果摘要和下一步建议 |
| 失败 | 展示原因和可操作下一步，不暴露技术堆栈 |

### 3.6 验收标准

- 学生无需进入其他页面，即可完成一次“目标输入 - 任务生成 - 确认创建”。
- 欢迎态必须显示不少于 6 个预设入口。
- 专业性回答必须展示引用来源。
- 创建任务、保存诊断、更新掌握度必须出现确认门。
- 执行轨迹至少展示工具名、状态、耗时和是否写操作。

## 4. 预设学习页面

### 4.1 页面定位

解决学生“不知道该问什么、不知道从哪里学起”的问题。预设学习不是传统课程目录，而是围绕数据类型、行业场景、岗位能力和证书目标组织的学习入口。

### 4.2 页面结构

```text
预设学习
├── 顶部筛选
│   ├── 数据类型：文本 / 图像 / 语音 / 视频
│   ├── 行业场景：通用 / 医疗 / 客服 / 车载 / 内容安全
│   ├── 学习目标：入门 / 专项 / 考证 / 岗位任务
│   └── 难度：1-5
├── 推荐路径区
│   ├── 新手路径
│   ├── 岗位胜任路径
│   ├── 证书备考路径
│   └── 薄弱补强路径
├── 学习单元列表
│   ├── 微课
│   ├── 规范讲解
│   ├── 案例练习
│   └── 模拟任务
└── 右侧说明
    ├── 当前路径能力图谱
    ├── 预计时长
    └── 开始学习按钮
```

### 4.3 首期预设路径

| 路径 | 数据类型 | 场景 | 关联能力 |
|------|----------|------|----------|
| 数据标注零基础入门 | 通用 | 通用 | 标注流程、格式规范、质量标准 |
| NER 实体标注入门 | 文本 | 通用 | 实体识别、边界划分、BIO 标注 |
| 客服情感标注 | 语音 / 文本 | 智能客服 | 情感标签、副语言、服务质检 |
| 车载唤醒词标注 | 语音 | 车载语音助手 | 唤醒词边界、正负例、噪声判定 |
| 图像目标检测标注 | 图像 | 通用 | 框选规范、类别标注、IOU 判定 |
| 视频片段事件标注 | 视频 | 内容安全 / 通用 | 时间片段、事件边界、目标跟踪 |
| 1+X 数据标注考证路径 | 通用 | 通用 | 证书考点、模拟题、专项练习 |

### 4.4 验收标准

- 学生可在 3 次点击内从预设学习开始任务。
- 每条预设路径至少关联 1 个能力节点、1 个知识节点、1 个资源和 1 个练习。
- 已掌握能力默认折叠，薄弱能力优先展示。

### 5.1 页面结构

```text
能力图谱
├── 顶部工具栏
│   ├── 搜索能力 / 知识 / 任务

│   └── 视图模式：全图 / 局部 / 路径
├── 主图谱区
│   ├── 能力节点
│   ├── 知识节点
│   ├── 任务节点
│   ├── 场景节点
│   ├── 资源节点
│   └── 证书节点
├── 节点详情抽屉
│   ├── 节点说明
│   ├── 前置能力
│   ├── 关联资源
│   ├── 典型任务
│   ├── 掌握度
```

- 166 节点全图可加载。
- 局部子图渲染 <= 500ms。
- PRE 路径必须无环。
- 能力节点可跳转到相关学习任务和证书考核点。

```text
标注诊断

│   ├── 支持格式说明

│   ├── 数据类型选择

│   ├── 字段识别
```

```text
├── 问答输入区
│   ├── 问题输入
│   ├── 场景筛选
│   ├── 数据类型筛选
│   └── 是否仅检索已发布资料
├── 答案区
│   ├── 直接回答
│   ├── 分步骤说明
│   ├── 注意事项
│   └── 追问建议
├── 引用来源区
│   ├── 文档名称
│   ├── 页码 / 段落 / 切片
│   ├── 版本
│   └── 可信等级

    ├── 相关能力
```

- 专业回答必须展示引用来源。
- 无召回结果时不得编造答案。
- 支持从问答结果一键生成学习任务卡预览。
