> 文档版本：v3.1  
> 更新日期：2026-08-06

---

## 1. 教师端定位

教师端面向实训教师和教研负责人，核心目标是把企业岗位任务转化为课堂任务，并基于学生学习数据进行教学干预。

教师端首期不追求复杂教务系统能力，而是优先支撑赛事演示和真实课堂闭环。

教师账号仅使用教师端的教学任务、班级和学情能力，不能进入学生端或 RAG 管理端；RAG 资料的上传、审核、发布和测试均由系统管理员在 RAG 管理端完成。

## 5. 教学任务发布

### 5.1 页面定位

教师将企业岗位任务、实训项目或教学目标转化为课堂可执行任务，并发布给班级。

### 5.2 页面结构

```text
教学任务发布
├── 任务来源
│   ├── 手动输入岗位任务
│   ├── 从已发布合规资料选择
│   ├── 从预设任务模板选择
│   └── 从历史任务复制
├── 任务生成
│   ├── Agent 生成任务卡
│   ├── 能力图谱定位
│   ├── 已发布资料引用
│   └── 难度与时长建议
├── 教师编辑
│   ├── 修改目标
│   ├── 修改步骤
│   ├── 添加资源
│   └── 设置评分规则
└── 发布设置
    ├── 选择班级
    ├── 截止时间
    ├── 是否计入掌握度
    └── 发布确认
```

### 5.3 交互流程

```text
教师输入企业任务
  ↓
Agent 识别岗位、数据类型、场景
  ↓
从已发布合规资料中选择引用
  ↓
能力图谱定位能力节点
  ↓
生成学习任务卡预览
  ↓
教师编辑
  ↓
选择班级和截止时间
  ↓
确认发布
```

### 5.4 验收标准

- 任务发布前必须展示预览。
- 任务必须至少关联一个能力节点和一个来源资料。
- 发布后学生任务列表可见。
- 教师编辑后的内容保留版本记录。
- 教师资料选择器仅返回已发布、学生可见、已授权且未过期的资料；不提供 RAG 管理或资源审核入口。

## 6. 学情分析

### 6.1 页面结构

```text
学情分析
├── 班级能力热力图
│   ├── 能力节点
│   ├── 平均掌握度
│   └── 薄弱人数
├── 学生个人能力地图
├── 任务完成趋势
├── 高频错误统计
├── 场景掌握度对比
└── 教学干预建议
```

### 6.2 筛选条件

| 筛选项 | 说明 |
|--------|------|
| 班级 | 选择教师有权限的班级 |
| 数据类型 | 文本 / 图像 / 语音 / 视频 |
| 行业场景 | 通用 / 医疗 / 客服 / 车载 / 内容安全 |
| 任务来源 | Agent 创建 / 预设学习 / 教师发布 / 诊断补强 |
| 时间范围 | 最近 7 天 / 30 天 / 本学期 |

### 6.3 验收标准

- 教师可查看班级整体薄弱能力。
- 教师可按数据类型、场景、任务来源筛选。
- 教学干预建议必须基于真实学习数据。
