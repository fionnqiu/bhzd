## 1. 模块定位

RAG 知识库管理系统是标航智导的专业内容底座。

它负责把教材、规范、案例、任务文件、证书标准和教师自建资料转化为可召回、可引用、可审核、可评测、可版本管理的知识资产。

RAG 管理门户、全部 RAG 管理 HTTP API 以及 Agent 资料管理工具仅允许 `system_admin` 使用。教师、内容管理员和学生均不得访问；教师发布任务时仅通过教师域的只读资料选择器查看已发布、学生可见、授权有效且未过期的资料。

### 4.2 资料状态

| 状态 | 说明 |
|------|------|
| draft | 已上传，未解析 |
| parsing | 正在解析 |
| parsed | 已解析，待切片 |
| chunking | 正在切片 |
| indexed | 已向量化入库 |
| review_pending | 待审核 |
| published | 已发布，可被学生端召回 |
| rejected | 审核驳回 |
| archived | 已归档，不参与召回 |
| failed | 处理失败 |

## 5. 资料上传

### 5.1 页面结构

```text
资料上传
├── 上传区
│   ├── 拖拽上传
│   ├── 文件选择
│   └── 批量上传
├── 元数据填写
│   ├── 资料标题
│   ├── 资料类型
│   ├── 来源单位 / 作者
│   ├── 来源链接 / 台账编号
│   ├── 版本号
│   ├── 适用数据类型
│   ├── 适用行业场景
│   ├── 关联能力节点
│   └── 可见范围
├── 处理配置
│   ├── 解析方式
│   ├── 切片策略
│   ├── 是否 OCR
│   ├── 是否生成摘要
│   └── 是否自动送审
└── 上传确认
```

### 5.2 必填字段

| 字段 | 说明 |
|------|------|
| 标题 | 学生端引用来源展示名 |
| 来源 | 教材、规范、教师自建、企业资料等 |
| 版本 | 资料变更追踪 |
| 适用场景 | 通用或具体行业场景 |
| 适用数据类型 | text / image / audio / video |
| 可见范围 | 管理员、教师、学生 |
| 授权状态 | 确认资料可用于教学系统 |

### 5.3 验收标准

- 未填写来源和授权状态时不得上传。
- 上传后进入异步处理队列。
- 上传完成后可查看解析日志。

## 6. 资料详情

```text
资料详情
├── 基本信息
├── 文件预览
├── 解析文本
├── 切片列表
├── 向量索引状态
├── 关联能力 / 课程 / 任务
├── 召回记录
├── 版本历史
└── 审核记录
```

核心操作：

| 操作 | 权限 | 说明 |
|------|------|------|
| 重新解析 | 系统管理员 | 文件解析失败或策略调整后使用 |
| 重新切片 | 系统管理员 | 修改切片策略后使用 |
| 重新索引 | 系统管理员 | 嵌入模型或索引异常时使用 |
| 编辑元数据 | 系统管理员 | 修改场景、类型、来源等 |
| 送审 | 系统管理员 | 提交系统管理员发布审核 |
| 发布 | 系统管理员 | 发布后进入学生端召回 |
| 归档 | 系统管理员 | 不再参与召回 |

教师资源审核已移除；资料审核、发布和归档均在系统管理员 RAG 管理端完成。

## 11. 召回评测集

```text
召回评测集
├── 问题列表
├── 标准答案
├── 必须命中文档
├── 必须命中切片
├── 运行评测
├── 评测结果
└── 历史对比
```

核心指标：

| 指标 | 说明 |
|------|------|
| Recall@K | TopK 中是否召回目标资料 |
| Citation Accuracy | 引用是否准确 |
| Answer Faithfulness | 答案是否忠于资料 |
| Refusal Accuracy | 资料不足时是否拒答 |
| Latency | 召回与生成耗时 |

## 12. RAG 标准处理流程

```text
资料上传
  ↓
元数据校验
  ↓
文本解析 / OCR
  ↓
结构清洗
  ↓
切片
  ↓
关键词与摘要生成
  ↓
系统管理员审核
  ↓
向量化
  ↓
索引发布
  ↓
召回测试
  ↓
学生端可用
```

## 13. RAG 召回流程

```text
用户问题
  ↓
意图识别与场景识别
  ↓
查询改写
  ↓
元数据过滤
  ↓
向量召回
  ↓
关键词混合召回
  ↓
重排序
  ↓
证据压缩
  ↓
LLM 生成答案
  ↓
引用来源校验
  ↓
返回答案
```
