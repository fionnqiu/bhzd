## 1. 系统管理端定位

系统管理端面向系统管理员，负责模型接入、RAG 参数、用户权限、安全配置和审计。

该区域不在学生端导航中展示，使用独立入口、独立会话和更严格的安全策略。

### 3.3 验收标准

- API Key 使用 AES-256-GCM 加密。
- 明文密钥不出现在数据库、日志和测试快照。
- 支持一个主模型和一个回退模型。
- 连接测试记录延迟、模型名、状态和错误信息。

### 4.1 页面结构

```text
RAG 参数配置
├── 切片参数
│   ├── chunk_size
│   ├── chunk_overlap
│   ├── 标题继承
│   └── 表格处理策略

    ├── 是否要求人工审核
    ├── 学生端可见范围

```

### 4.2 验收标准

- 参数修改必须记录审计日志。
- 参数修改后支持用评测集回归测试。
- 召回参数必须有默认安全值，避免召回未审核资料。

## 5. 用户与权限

### 5.1 角色权限矩阵

| 功能 | 学生 | 教师 | 内容管理员 | 系统管理员 |
|------|------|------|------------|------------|
| 学生端门户及其 API | 可用 | 不可用 | 可用 | 可用 |
| Agent 对话 | 可用 | 不可用 | 可用 | 可用 |
| 预设学习 | 可用 | 不可用 | 可用 | 可用 |
| 创建个人任务 | 可用 | 不可用 | 可用 | 可用 |
| 发布班级任务 | 不可用 | 可用 | 可用 | 不默认开放 |
| 进入 RAG 管理门户、调用 RAG 管理 HTTP API 或 Agent 资料管理工具 | 不可用 | 不可用 | 不可用 | 可用 |
| 上传 RAG 资料 | 不可用 | 不可用 | 不可用 | 可用 |
| 审核 / 发布 RAG 资料 | 不可用 | 不可用 | 不可用 | 可用 |
| 配置模型供应商 | 不可用 | 不可用 | 不可用 | 可用 |
| 查看审计日志 | 不可用 | 部分 | 部分 | 可用 |

### 5.2 验收标准

- 学生不能进入教师端、RAG 管理端和系统管理端。
- 教师不能进入学生端或 RAG 管理端；直接访问学生端 API、RAG 管理 HTTP API 或 Agent 资料管理工具必须返回 403。
- 内容管理员和系统管理员保留学生端访问权限。
- RAG 管理门户、RAG 管理 HTTP API、资料审核与 Agent 资料管理工具仅允许系统管理员。
- 教师只能查看自己班级数据。
- 内容管理员不能默认查看系统密钥。
- 权限变更必须进入审计日志。

## 6. 安全配置

| 编号 | 需求 | 优先级 |
|------|------|--------|
| NF1 | 密码使用 Argon2id 哈希 | P0 |
| NF2 | API Key 使用 AES-256-GCM 加密 | P0 |
| NF3 | 学生上传诊断原文件不持久化 | P0 |
| NF4 | 学生、教师、管理员会话隔离 | P0 |
| NF5 | 登录限流、失败锁定、CSRF 防护 | P0 |
| NF6 | RAG 上传资料必须记录授权状态 | P0 |
| NF7 | 未发布资料不得被学生端召回 | P0 |
| NF8 | 审核、发布、删除、归档必须进入审计日志 | P0 |
| NF9 | base_url 拒绝本机、内网元数据、危险转发头 | P0 |

## 7. 审计日志

### 7.1 审计对象

| 对象 | 事件 |
|------|------|
| 用户 | 登录、登出、失败登录、密码重置 |
| 模型供应商 | 新增、编辑、删除、连接测试、角色切换 |
| RAG 资料 | 上传、解析、切片、索引、送审、发布、归档、删除 |
| 权限 | 用户角色变更、班级权限变更、资料可见范围变更 |
| Agent | 写操作确认、取消、失败 |

### 7.2 日志字段

| 字段 | 说明 |
|------|------|
| id | 日志 ID |
| actor_id | 操作人 |
| actor_role | 操作人角色 |
| action | 操作类型 |
| target_type | 目标类型 |
| target_id | 目标 ID |
| before | 变更前摘要 |
| after | 变更后摘要 |
| ip | IP |
| user_agent | 浏览器信息 |
| created_at | 时间 |
