# 标航智导 PRD 06：研发可落地补充与边界条件

> 文档版本：v3.1  
> 更新日期：2026-08-06  
> 文档定位：基于真实研发交付视角，对总览 PRD、学生端 PRD、教师端 PRD、RAG 管理 PRD、系统管理 PRD 的遗漏点、边界条件、验收矩阵和风险兜底进行补强。  
> 方法说明：本补充采用 letty-memory 中的产品判断框架：先校准 P0 基本盘，再处理 P1 痛点；按信息可得性划分职责；不把用户诉求直接等同于功能方案；每个关键规则必须说明触发条件、行为、例外和验收方式。

---

## 1. 补强结论总览

### 1.1 当前 PRD 已具备的主干

当前 PRD 已经覆盖：

| 能力 | 当前覆盖情况 |
|------|--------------|
| 学生学习入口 | Agent 指挥舱 + 预设学习 |
| 岗位能力图谱 | 节点、边、PRE 路径、掌握度 overlay |
| 企业任务转学习任务 | 任务卡预览、确认创建、教师发布 |
| 标注诊断 | 结构化文件上传、诊断报告、补强计划 |
| RAG 知识库 | 上传、解析、切片、审核、发布、召回、评测 |
| 系统管理 | 模型供应商、RAG 参数、权限、安全、审计 |

### 1.2 若交给真实开发，仍需补齐的关键缺口

| 缺口 | 风险 | 需要补充 |
|------|------|----------|
| 缺少产品 P0/P1 边界 | Agent 和 RAG 容易做散，研发无法判断取舍 | 明确 P0 基本盘、P1 增强项、P2 延后项 |
| 缺少账号与组织模型细节 | 班级、教师、管理员权限容易混乱 | 增加学校、班级、角色、邀请码、数据隔离 |
| 缺少资料安全与授权边界 | 真实资料上传后可能侵权、泄露或被错误召回 | 增加授权状态、脱敏、敏感信息检测、可见范围 |
| 缺少 RAG 失败与拒答规则 | 召回不到资料时容易幻觉 | 增加召回不足、引用冲突、资料过期、跨场景误召回处理 |
| 缺少 Agent 责任边界 | LLM 可能越权创建、更新掌握度或生成不可信评分 | 增加工具权限、确认门、只读/写操作边界 |
| 缺少异步任务状态 | 解析、切片、索引、评测都是异步，前端状态不清 | 增加任务状态机、重试、取消、失败恢复 |
| 缺少数据版本和回滚 | 资料、切片、图谱更新后结果不可追溯 | 增加版本、发布批次、索引版本、引用快照 |
| 缺少验收矩阵 | 只有单点验收，缺少边界测试 | 增加核心流程验证矩阵 |
| 缺少运营与演示数据方案 | 比赛演示可能受真实模型、网络、资料不足影响 | 增加种子数据、演示模式、降级策略 |

## 2. 产品优先级与取舍边界

### 2.1 P0 基本盘

P0 是系统不可牺牲的基本价值。任何优化不能伤害这些能力。

| P0 基本盘 | 说明 | 不可接受的损害 |
|-----------|------|----------------|
| 学生能开始学习 | 不知道问什么时也能从预设学习进入 | 首页只有空输入框，学生无从下手 |
| 专业回答有依据 | 涉及规范、教材、规则时必须引用 RAG 来源 | 模型凭空回答或没有引用 |
| 任务能闭环 | 目标输入或预设入口能生成学习任务并完成反馈 | 只能聊天，不能落到任务 |
| 诊断可信 | 标注诊断由确定性规则完成，LLM 只解释 | LLM 直接判断对错和扣分 |
| 资料可治理 | 资料必须审核发布后才能给学生召回 | 上传后立即对学生可见 |
| 写操作可控 | 创建、发布、保存、更新都需要确认 | Agent 自动写入用户状态 |

### 2.2 P1 增强项

| P1 增强项 | 价值 | 边界 |
|-----------|------|------|
| 教师学情分析 | 帮助教师干预教学 | 首期只做基础热力图和薄弱 TopN |
| 切片编辑器 | 提升 RAG 召回质量 | 首期可只支持文本切片编辑 |
| 召回评测集 | 保障 RAG 质量 | 首期覆盖 20-50 个标准问题即可 |
| 教师任务发布 | 对齐岗课转换 | 首期可先支持单班级发布 |

### 2.3 P2 延后项

| P2 项 | 延后原因 |
|-------|----------|
| OCR 图片资料解析 | 解析质量和校验成本高 |
| 音视频转写入库 | 依赖转写模型和人工校对 |
| 网页抓取 | 授权、变更、反爬和来源稳定性复杂 |
| 多校区组织 | 不是赛事 MVP 核心 |
| 复杂 BI 报表 | 可由基础数据导出替代 |

## 3. 账号、组织与权限补充

### 3.1 组织模型

```text
School
  └── Department / MajorGroup
        └── Class
              ├── TeacherClassRole
              └── StudentEnrollment
```

### 3.2 账号注册规则

| 场景 | 规则 |
|------|------|
| 学生自注册 | 通过邮箱注册，默认进入“未加入班级”状态 |
| 学生加入班级 | 使用教师邀请码或管理员导入 |
| 教师注册 | 需要管理员审核或邀请码 |
| 管理员创建 | 首个管理员由环境变量或初始化脚本创建 |
| 邮箱未验证 | 不允许使用 Agent 和 RAG 问答，只允许重发验证邮件 |

### 3.3 权限边界

| 数据 | 学生 | 教师 | 内容管理员 | 系统管理员 |
|------|------|------|------------|------------|
| 学生端门户及其 API | 可用 | 不可用 | 可用 | 可用 |
| RAG 管理门户、HTTP API 与 Agent 资料管理工具 | 不可见 | 不可见 | 不可见 | 可见 |
| 个人学习任务 | 只能看自己 | 可看所教班级汇总与任务结果 | 不默认可见 | 可按审计查看 |
| 诊断原文件 | 请求内解析，不持久化 | 不可见 | 不可见 | 不可见 |
| 诊断摘要 | 只能看自己 | 可看班级聚合与授权详情 | 不默认可见 | 可按审计查看 |
| 未发布 RAG 资料 | 不可见 | 不可见 | 不可见 | 可见 |
| API Key 明文 | 不可见 | 不可见 | 不可见 | 仅录入时可见一次 |

### 3.4 边界条件

| 场景 | 预期行为 |
|------|----------|
| 学生退出班级 | 保留个人学习数据，教师不再能看到该学生后续数据 |
| 教师离开班级 | 不删除班级任务和学生数据，转交给管理员或其他教师 |
| 邮箱重复注册 | 提示已存在，不暴露是否已验证 |
| 邀请码过期 | 提示联系教师重新获取 |
| 账号被禁用 | 终止会话，禁止 Agent 与 RAG 调用 |

## 4. RAG 资料治理补充

### 4.1 RAG 资料进场条件

资料进入知识库前必须满足以下条件：

| 条件 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 用于引用展示 |
| 来源类型 | 是 | 教材、规范、企业资料、教师自建、比赛资料等 |
| 授权状态 | 是 | authorized / internal / pending / forbidden |
| 适用数据类型 | 是 | text / image / audio / video |
| 适用场景 | 是 | 通用、医疗、客服、车载、内容安全 |
| 可见范围 | 是 | 管理员、教师、学生 |
| 版本 | 是 | 用于追溯 |
| 上传人 | 是 | 审计 |

### 4.2 资料不得发布的情况

| 情况 | 系统行为 |
|------|----------|
| 授权状态为 forbidden | 禁止发布 |
| 授权状态为 pending | 可解析但不可学生端召回 |
| 缺少来源 | 禁止送审 |
| 检测到明显敏感信息 | 进入脱敏待处理状态 |
| 文档解析失败 | 不允许索引 |
| 切片为空 | 不允许发布 |
| 审核驳回 | 不参与召回 |
| 已过有效期 | 自动从学生端召回范围移除 |

### 4.3 资料敏感信息检测

首期至少检测：

| 类型 | 示例 | 处理 |
|------|------|------|
| 手机号 | 11 位手机号 | 提示脱敏 |
| 身份证 | 18 位身份证号 | 阻止发布 |
| 邮箱 | 个人邮箱 | 提示脱敏 |
| 学生姓名 + 学号 | 班级名单 | 阻止学生端发布 |
| 企业内部标识 | 工单号、客户号 | 提示脱敏 |

### 4.4 RAG 召回边界

| 场景 | 规则 |
|------|------|
| 无召回结果 | 明确提示知识库暂无可靠依据，不生成专业结论 |
| 召回分数低于阈值 | 不回答或只给通用学习建议 |
| 召回资料场景冲突 | 优先当前场景；提示存在其他场景规则 |
| 通用规则与场景规则冲突 | 已发布场景规则优先 |
| 多资料版本冲突 | 最新已发布版本优先，同时显示版本 |
| 来源过期 | 不参与学生端召回 |
| 用户要求引用未发布资料 | 拒绝，并提示资料未发布 |

### 4.5 引用展示规则

| 字段 | 学生端是否展示 | 说明 |
|------|----------------|------|
| 文档标题 | 是 | 例如《智能客服语音标注规范 v2.3》 |
| 章节标题 | 是 | 可为空 |
| 页码 / 段落 | 是 | PDF 展示页码，Markdown 展示标题 |
| 版本 | 是 | 避免引用过期资料 |
| 上传人 | 否 | 后台可见 |
| 切片 ID | 调试态展示 | 学生默认不展示 |

## 5. RAG 状态机与异步任务

### 5.1 资料状态机

```text
draft
  ↓ submit
parsing
  ├── failed
  ↓
parsed
  ↓ chunk
chunking
  ├── failed
  ↓
chunked
  ↓ index
indexing
  ├── failed
  ↓
indexed
  ↓ submit_review
review_pending
  ├── rejected
  ↓ approve
published
  ├── archived
  └── expired
```

### 5.2 异步任务通用规则

| 场景 | 规则 |
|------|------|
| 重复提交同一任务 | 使用幂等 key，避免重复解析 |
| 任务失败 | 保留错误码、错误信息、阶段、重试次数 |
| 任务重试 | 从失败阶段重试，不重复已成功阶段 |
| 参数变化 | 必须生成新的处理版本 |
| 删除资料 | 已发布资料只能归档，不能物理删除 |
| 重新索引 | 新索引成功后再切换，避免召回中断 |

### 5.3 失败错误码

| 错误码 | 说明 | 用户提示 |
|--------|------|----------|
| PARSE_UNSUPPORTED | 文件格式暂不支持 | 请上传 PDF、Word 或 Markdown |
| PARSE_EMPTY_TEXT | 未解析出文本 | 文档可能是扫描件，请开启 OCR 或换文件 |
| CHUNK_EMPTY | 切片为空 | 请检查解析文本 |
| EMBEDDING_FAILED | 向量化失败 | 模型连接异常，请稍后重试 |
| REVIEW_REQUIRED | 未审核 | 资料需要审核后才能发布 |
| LICENSE_BLOCKED | 授权不允许 | 资料授权状态不允许发布 |

## 6. Agent 编排边界补充

### 6.1 Agent 可做与不可做

| 类型 | 可做 | 不可做 |
|------|------|--------|
| 学习建议 | 根据 RAG 和图谱生成建议 | 无依据编造专业规范 |
| 任务卡 | 生成任务卡预览 | 未确认直接创建任务 |
| 诊断 | 解释确定性诊断结果 | 自行决定评分和扣分 |
| 掌握度 | 展示更新预览 | 未确认直接更新 |
| 资料管理 | 帮管理员生成元数据草稿 | 未审核直接发布资料 |
| 教师任务 | 生成发布预览 | 未经教师确认发布到班级 |

### 6.2 Agent 信息不足追问规则

每轮只问一个最能缩小范围的问题。

| 信息缺口 | 优先追问 |
|----------|----------|
| 不知道数据类型 | “你要学习的是文本、图像、语音还是视频标注？” |
| 不知道场景 | “这次任务更接近通用、客服、车载、医疗还是内容安全场景？” |
| 不知道目标 | “你是想学习规范、完成任务，还是诊断已有标注结果？” |
| 文件格式不明确 | “这个文件是从哪个标注工具导出的？” |

### 6.3 计划生成边界

| 场景 | 计划要求 |
|------|----------|
| 纯知识问答 | 最多 3 步：召回资料、生成答案、展示引用 |
| 任务转化 | 至少包含 RAG 召回、图谱定位、任务卡生成 |
| 标注诊断 | 至少包含格式校验、规则诊断、依据召回、补强路径 |
| 预设学习 | 至少包含路径选择、任务创建、练习反馈 |

### 6.4 确认门规则

| 写操作 | 确认内容 | 过期时间 |
|--------|----------|----------|
| 创建学习任务 | 任务名称、目标、步骤、关联能力 | 30 分钟 |
| 保存诊断摘要 | 错误数量、薄弱能力、掌握度变化 | 30 分钟 |
| 更新掌握度 | old_score、new_score、来源 | 30 分钟 |
| 发布班级任务 | 班级、截止时间、任务内容 | 30 分钟 |
| 发布 RAG 资料 | 资料、版本、可见范围 | 30 分钟 |
| 删除 / 归档 | 影响范围 | 10 分钟 |

过期后用户必须重新生成预览，防止基于旧状态写入。

## 7. 学生端边界补充

### 7.1 首页信息架构取舍

首页 P0 是“让学生开始学习”，不是“展示全部功能”。因此首页默认展示：

| 区域 | 是否默认展开 |
|------|--------------|
| 目标输入框 | 是 |
| 预设学习快捷卡 | 是 |
| 今日推荐 | 是 |
| 执行轨迹 | 折叠 |
| 引用来源 | 有结果后展示 |
| 完整能力图谱 | 不在首页默认展示 |

### 7.2 空状态处理

| 页面 | 空状态 |
|------|--------|
| Agent 指挥舱 | 展示 8 个预设入口和 3 个示例问题 |
| 学习任务列表 | 提示从预设学习、教师任务或 Agent 创建任务 |
| 诊断摘要 | 提示上传一次标注结果进行诊断 |
| 能力图谱 | 默认展示岗位胜任路径，不展示空白画布 |
| 知识问答 | 展示常见规范问题示例 |

### 7.3 场景切换边界

| 场景 | 规则 |
|------|------|
| 学生手动切换场景 | 当前会话后续工具使用新场景 |
| Agent 识别到其他场景关键词 | 只建议切换，不自动切换 |
| 切换场景后已有任务 | 不改变历史任务场景 |
| 诊断文件已有场景元数据 | 优先提示用户确认是否使用文件场景 |

## 8. 任务与掌握度边界补充

### 8.1 任务状态机

```text
draft
  ↓ confirm_create
not_started
  ↓ start
in_progress
  ├── submit
  │     ↓
  │   submitted
  │     ↓ grade
  │   completed
  ├── pause
  │     ↓
  │   paused
  └── archive
        ↓
      archived
```

### 8.2 任务来源

| 来源 | 是否可删除 | 是否计入掌握度 |
|------|------------|----------------|
| Agent 创建 | 可删除 | 可选 |
| 预设学习 | 可归档 | 默认计入 |
| 教师发布 | 学生不可删除，只可完成或归档显示 | 由教师设置 |
| 诊断补强 | 可归档 | 默认计入 |

### 8.3 掌握度更新边界

| 场景 | 更新规则 |
|------|----------|
| 通用练习 | 只更新 general_mastery |
| 场景练习 | 只更新 CAP + SCN 的 scenario_mastery |
| 诊断摘要 | 用户确认后才更新 |
| 教师发布任务 | 根据教师设置决定是否更新 |
| 重复提交 | 保留 attempt_number，按最新有效提交更新 |
| 用户删除任务 | 不回滚已确认的掌握度，只隐藏任务 |

### 8.4 掌握度冲突处理

| 冲突 | 处理 |
|------|------|
| 同一能力多次练习分数不同 | 按时间序列更新，保留历史 |
| 通用能力高、场景能力低 | 场景内显示场景掌握度，通用视图显示通用掌握度 |
| 场景能力缺失 | 显示通用掌握度作为参考，并标注“未完成该场景测评” |
| 诊断扣分导致低于 0 | clamp 到 0 |
| 练习提升导致高于 1 | clamp 到 1 |

## 9. 标注诊断边界补充

### 9.1 文件上传限制

| 限制 | 首期建议 |
|------|----------|
| 单文件大小 | <= 20MB |
| 单次文件数 | 1 个 |
| 支持格式 | JSON / TextGrid / COCO JSON / VOC XML |
| 图片截图 | 仅辅助讲解，不参与自动评分 |
| 原文件保存 | 不持久化 |

### 9.2 诊断失败处理

| 场景 | 行为 |
|------|------|
| 格式无法解析 | 返回格式错误和示例模板 |
| 字段缺失 | 指出缺少字段，不进入评分 |
| 数据类型与场景不匹配 | 提示用户确认场景 |
| 规则库无对应规则 | 不扣分，提示当前规则库暂未覆盖 |
| RAG 未召回依据 | 可展示结构化错误，但不生成专业规范解释 |

### 9.3 诊断报告最低结构

| 字段 | 必须 |
|------|------|
| 错误类型 | 是 |
| 严重程度 | 是 |
| 用户标注值 | 是 |
| 期望值或规则说明 | 是 |
| 规则依据 | 有 RAG 命中时必须 |
| 图谱能力节点 | 是 |
| 建议补强任务 | 是 |

## 10. 教师端边界补充

### 10.1 教师任务发布规则

| 场景 | 规则 |
|------|------|
| 发布给多个班级 | P1 支持；MVP 先支持单班级 |
| 修改已发布任务 | 生成新版本，不直接覆盖学生已开始任务 |
| 删除已发布任务 | 已有人完成时只能归档 |
| 截止时间变更 | 通知学生并记录审计 |
| 任务计入掌握度 | 发布时由教师选择 |
| 任务资料选择 | 仅返回已发布、学生可见、授权有效且未过期的资料；教师不进入 RAG 管理端 |

### 10.2 学情分析边界

| 场景 | 规则 |
|------|------|
| 班级学生少于 3 人 | 聚合报表提示样本过小 |
| 学生未授权详细数据 | 教师只能看聚合数据 |
| 教学干预建议 | 必须基于薄弱能力、错误统计或任务完成数据 |
| 导出报表 | 不包含诊断原文件 |

## 11. 系统降级与演示模式

### 11.1 模型降级

| 故障 | 降级 |
|------|------|
| 主模型失败 | 自动切换回退模型 |
| 回退模型也失败 | 展示工具结果，不生成自然语言总结 |
| 嵌入模型失败 | 暂停新资料索引，已索引资料仍可召回 |
| 重排模型失败 | 使用向量召回原始排序 |

### 11.2 RAG 降级

| 故障 | 降级 |
|------|------|
| 向量库不可用 | 使用关键词检索 |
| 关键词检索也失败 | 拒答专业问题，保留预设学习入口 |
| 单个资料索引失败 | 不影响其他已发布资料 |
| 召回超时 | 返回超时提示和重试按钮 |

### 11.3 比赛演示模式

为了避免现场网络和模型波动影响演示，系统应支持演示模式：

| 能力 | 规则 |
|------|------|
| 演示资料集 | 内置已审核、已发布资料 |
| 演示问题 | 内置标准问题和预期召回 |
| 演示任务 | 内置“客服语音情感标注”和“车载唤醒词标注” |
| 演示诊断文件 | 内置可复现错误样例 |
| 标识 | 演示模式必须在后台显示，学生端比赛演示可隐藏 |

## 12. 数据留存、删除与合规

### 12.1 数据留存

| 数据 | 留存规则 |
|------|----------|
| 会话消息 | 用户可删除；默认保留用于学习连续性 |
| ToolCall 摘要 | 保留工具名、参数摘要、结果摘要 |
| 上传诊断原文件 | 不持久化 |
| 诊断摘要 | 用户确认后保存 |
| RAG 原始资料 | 管理端保存，支持归档 |
| RAG 切片 | 随资料版本保存 |
| 审计日志 | 不允许普通用户删除 |

### 12.2 删除规则

| 操作 | 行为 |
|------|------|
| 用户删除会话 | 删除消息和可见工具摘要，审计日志保留 |
| 用户删除任务 | 隐藏或归档任务，不回滚已确认掌握度 |
| 管理员归档资料 | 学生端不再召回，历史引用仍保留快照 |
| 管理员删除未发布资料 | 可物理删除，但保留操作日志 |

## 14. 核心验证矩阵

### 14.1 学生学习闭环

| 场景 | 输入 | 预期结果 |
|------|------|----------|
| 不知道学什么 | 打开首页不输入 | 展示预设学习和今日推荐 |
| 明确目标 | “我想学车载唤醒词标注” | 识别语音 + 车载场景，生成任务卡 |
| 信息不足 | “我想学标注” | 只追问一个问题 |
| 创建任务 | 确认任务卡 | 写入任务列表 |
| 取消任务 | 取消确认 | 不改变学习状态 |

### 14.2 RAG 召回闭环

| 场景 | 输入 | 预期结果 |
|------|------|----------|
| 命中已发布资料 | 问规范问题 | 返回答案和引用 |
| 无资料命中 | 问知识库没有的问题 | 拒答或提示资料不足 |
| 未审核资料 | 问只存在于未审核资料的问题 | 学生端不可召回 |
| 场景冲突 | 客服问题召回车载资料 | 降权或提示场景不匹配 |
| 资料过期 | 引用过期资料 | 不参与学生端召回 |

### 14.3 诊断闭环

| 场景 | 输入 | 预期结果 |
|------|------|----------|
| 合法 JSON | 上传结构化结果 | 输出诊断报告 |
| 非法格式 | 上传错误文件 | 返回格式错误 |
| 规则未覆盖 | 上传未知任务 | 不扣分，提示暂未覆盖 |
| 保存摘要 | 用户确认 | 保存摘要并更新掌握度 |
| 取消保存 | 用户取消 | 不更新掌握度 |

### 14.4 教师闭环

| 场景 | 输入 | 预期结果 |
|------|------|----------|
| 生成任务 | 输入企业任务 | 生成任务卡预览 |
| 发布任务 | 选择班级确认 | 学生任务列表可见 |
| 修改任务 | 修改已发布任务 | 生成新版本 |
| 归档任务 | 已有学生完成 | 归档而非删除 |

## 15. 待产品确认项

| # | 问题 | 建议结论 |
|---|------|----------|
| 1 | 首期是否支持学校 / 专业群多租户 | MVP 可先单学校，但数据模型预留 school_id |
| 2 | 教师是否能查看学生诊断详情 | 默认只能看聚合，学生授权后看详情 |
| 3 | RAG 资料是否允许学生上传 | 首期不允许，避免资料污染和版权风险 |
| 4 | 是否必须接入讯飞星辰平台 | 比赛提交应优先适配，系统保留通用协议 |
| 5 | 诊断原文件是否保存 | 不保存，只保存摘要和统计 |
| 6 | 教师任务是否默认计入掌握度 | 默认由教师发布时选择 |
| 7 | 未审核资料能否用于教师端 | 不可以。教师不可预览、测试或管理未审核资料；任务资料选择器仅返回已发布合规资料 |
| 8 | 学生端是否展示完整工具参数 | 默认不展示，调试模式展示 |
| 9 | 演示模式是否进入正式版本 | 可以保留后台开关，但需明确标识 |
