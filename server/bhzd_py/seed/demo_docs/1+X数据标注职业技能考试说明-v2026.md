# 1+X 数据标注职业技能考试说明 v2026

本说明面向参加 1+X 数据标注职业技能等级证书（中级）考试的学员，依据 2026 年最新考核大纲编写，覆盖考试结构、核心考点与评分规则。

## 考试结构

考试分理论与实操两部分，总时长 150 分钟。理论部分 60 题，覆盖标注基础概念、常用格式（JSON、XML、TextGrid、COCO、VOC）与质量管理方法；实操部分要求在指定平台完成三个真实标注任务：文本分类、图像矩形框标注、语音片段切分与转写，系统自动比对标准答案评分。

## 核心考点

图像方向：矩形框贴边要求（框边缘与目标最外像素距离不超过 2 像素）、遮挡目标的可疑区域估计、IOU（交并比）计算与合格线（实操题 IOU ≥ 0.85 得分）。语音方向：有效语音段起止判定、静音与背景噪声的区分、说话人分离标签使用。文本方向：类别定义边界、多标签场景的主次标签顺序、标签体系合法性校验。通用方向：质检抽样比例、错误分级（一级致命、二级严重、三级轻微）与返工流程。

## 评分规则

实操评分以任务为单位：文本分类按准确率计；图像标注按框级 IOU 匹配后的 F1 计；语音按边界误差与转写准确率加权计。任一任务出现一级错误（如类别体系用错、文件格式非法无法解析）该任务直接判零分。总分 100 分，70 分合格，85 分以上为优秀。

## 备考建议

先通读项目标注规范再上机练习，规范中"边界""容差""枚举值"三类条款是最高频考点。建议按"文本→图像→语音"的顺序专项突破，每个方向至少完成两轮带质检反馈的练习批次，并整理个人错题本记录边界误判案例。考前一周用模拟卷计时训练，重点控制语音切分的时间分配。

## 版本变更说明

v2026 相对 v2025：实操图像任务 IOU 合格线由 0.80 提升至 0.85；新增 VOC XML 格式识读考点；理论题量增加质量管理方法比重。
