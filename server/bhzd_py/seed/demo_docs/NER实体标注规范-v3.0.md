# NER 实体标注规范 v3.0

本规范定义命名实体识别（NER）任务的标注口径，适用于新闻、客服对话与文档抽取类文本。实体类型以项目标签集为准，常见类型包括 `PER`（人名）、`ORG`（机构名）、`LOC`（地名）、`TIME`（时间表达式）、`PRODUCT`（产品名）。

## BIO 边界规则

采用 BIO 标注体系：实体首字标 `B-类型`，后续字标 `I-类型`，非实体字标 `O`。实体边界取最小完整语义单元：修饰语、量词、标点一律不进实体。例如"北京中关村科技园区管委会"作为一个 `ORG` 整体标注，而其前的"位于"标 `O`。数字与单位组合的时间表达式整体标 `TIME`，如"2026 年 7 月"。

## 嵌套与歧义处理

不允许嵌套标注：当长短两个候选实体冲突时取最长完整实体。一词多义按上下文判定："苹果"在"苹果手机销量"中标 `PRODUCT`，在"每天吃一个苹果"中标 `O`（普通名词非命名实体）。实在无法判定的句子打 `uncertain` 标记并提交复核，复核结论回写规范附录。

## 标签一致性要求

同一文档内同一指称必须标同一类型，前后不一致属于二级错误。人名简称与全称视为同一实体类型；机构名的简称（如"北大"对应"北京大学"）同样标 `ORG`。跨句实体不合并，按各自出现位置独立标注。

## 质量指标

交付验收以实体级 F1 计算：精确率与召回率均不得低于 0.92，其中边界错误（类型正确但边界偏移）按半个错误计。每批次双人标注不一致率超过 8% 时启动第三人仲裁。常见扣分点：把机构名中的地名拆出单独标 `LOC`；时间表达式漏标年份后缀；口语文本中把称谓（"王总"）漏标为 `PER`。

## 版本变更说明
