# 智能客服语音标注规范 v2.3

本规范适用于智能客服场景的通话录音标注，覆盖转写、情感标签与副语言事件三类任务。所有标注结果以客户与坐席双声道分离后的音频为准，标注平台统一采用毫秒级时间戳。

## 转写与说话人分离

转写采用语义完整原则：口语中的语气词（"嗯""啊""那个"）保留原文，不做书面化改写；听不清的片段用 `[UNK]` 标记，禁止臆测补全。说话人标签固定为 `customer` 与 `agent` 两类，重叠语音按主声道归属，并在 `overlap` 字段标记为 true。单个切分段时长不得小于 200 毫秒，不得超过 30 秒。

## 情感标签判定

情感标签从项目给定枚举中选取：`satisfied`、`neutral`、`anxious`、`angry`、`confused`。判定依据以语音表现为准，不依赖文字内容推断。例如客户语速明显加快、音调升高且伴随叹气，应标 `anxious` 而非 `neutral`。同一片段出现情感转换时，以片段结束时的主导情感为准，并在备注中记录转折点时间。拿不准的样本必须提交复核，禁止强行归类。

## 副语言事件标注

笑声、叹气、咳嗽、长时间沉默（超过 2 秒）均需作为副语言事件单独记录，写入 `paralinguistic_events` 数组，字段包含事件类型与起止毫秒时间。事件边界从声音可辨识的起点算起，到能量衰减至背景噪声水平为止，左右各留不超过 50 毫秒余量。

## 质量要求与常见错误

交付前须通过自动质检：时间戳不得越界或倒置，相邻段间隔不得超过 500 毫秒未标注区间（静音段除外），情感标签必须来自枚举值。常见错误包括：把客户的反讽语句仅按字面标为 `satisfied`；漏标重叠段；副语言事件边界过宽导致混入正常语音。一级质检通过率低于 95% 的批次整批退回。

## 版本变更说明

v2.3 相对 v2.2：新增 `confused` 情感枚举；沉默阈值由 3 秒收紧为 2 秒；明确反讽语句须结合语调判定的条款。
