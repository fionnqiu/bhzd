# 车载唤醒词标注指南 v1.4

本指南面向车载语音助手项目的唤醒词数据标注，目标是为唤醒模型提供边界精确、正负例均衡的训练数据。车内环境噪声复杂，标注前请先完成一遍完整试听，确认音频采样率与声道配置无误。

## 唤醒词边界切分

唤醒词起点取首个音节能量上升沿之前不超过 30 毫秒处，终点取末音节能量衰减至背景噪声水平之后不超过 50 毫秒处。边界过宽会引入噪声导致误唤醒率上升，过窄会削掉音节首尾导致模型漏唤醒，因此边界误差控制在 ±50 毫秒以内。多字唤醒词内部不允许出现超过 300 毫秒的停顿，出现停顿的样本单独标记 `slow_speech` 属性。

## 正例与负例判定

正例：完整、清晰说出约定唤醒词，允许带方言口音与车内噪声。负例分三类必须区分标注：`near_miss`（近音词，如把"你好小航"说成"你好小方"）、`partial`（只说出一半唤醒词）、`noise_trigger`（广播、导航语音或乘客对话中出现的同音片段）。负例绝不删除，它们是抑制误唤醒的关键训练信号，占比应保持在 30% 以上。

## 噪声与重叠处理

车窗噪声、音乐声、多人交谈背景下的唤醒尝试仍然标注，并在 `snr_level` 字段按高/中/低三档估计信噪比。唤醒词与其他说话声完全重叠、无法辨识边界时，标记 `overlap=true` 并提交复核，不强行切分。

## 质检规则

每批次随机抽 10% 复检，边界误差超过 ±50 毫秒的样本占比大于 5% 时整批返工。负例类别混淆（如 `near_miss` 错标为 `partial`）属于一级错误，发现即整批退回。标注完成的数据按车型、麦克风阵列位置、车速区间分桶统计，任何分桶占比低于 5% 需补采。

## 版本变更说明

v1.4 相对 v1.3：负例新增 `noise_trigger` 类别；边界容差由 ±80 毫秒收紧至 ±50 毫秒；增加分桶均衡要求。
